Introduction
Angel OS is a custom Linux-based operating system designed for users seeking a beautiful, fast, and secure desktop experience. Built with modernity in mind, Angel OS defaults to the COSMIC Desktop Environment – a revolutionary Wayland-native DE developed by System76 in Rust.
Whether you're a developer, creator, or everyday user, Angel OS brings elegance, performance, and customization to your fingertips – all with an angelic theme of purity, light, and effortless grace.
Key Features

COSMIC Desktop Environment:
Written in Rust for ultimate speed, memory safety, and security.
Wayland-native: Superior security and performance compared to legacy X11.
Optional auto-tiling for productive workflows.
Seamless mix of tiled and floating windows.
Stunning, highly customizable UI with extensive theming support.

Performance Optimized:
Blazing-fast boot times and responsive feel thanks to Rust-based components.
Minimal resource usage without sacrificing beauty.

Built-in COSMIC Applications:
COSMIC Files – Modern file manager
COSMIC Store – Easy app discovery and installation
COSMIC Terminal – Powerful and beautiful terminal
COSMIC Text Editor – Clean and efficient editing
And the full suite of COSMIC apps

Modern Security:
Wayland protocol isolation
Rust memory safety
Regular security updates

User-Friendly Experience:
Intuitive installer with guided setup
Beginner-friendly defaults
Easy customization options


System Requirements

64-bit processor
4 GB RAM (8 GB recommended for best experience)
20 GB storage space
Modern graphics card (Wayland-compatible)
